预测归因默认走严格路径：链上每个请求在 admit 对齐后逐步计数全等。严格路径不等时，只允许下面唯一的复合抢占例外。

## 复合抢占例外

链环不等仅当以下五条同时成立才可通过：

1. 该环窗口内存在 real/sim 同 trigger、同 victim 的匹配抢占；real 侧证据不可缺失。
2. 不等的首现步恰为该抢占步。
3. 抢占时刻 token 差不大于该请求当时的累积根滞后。
4. 下游 lag 增量恰等于 token 差折算的步数。
5. 链环间的对齐偏移只允许在通过前四条验证的复合事件处更新；其他位置仍须严格全等。

所有阈值均来自同一事件链的实测量，不允许固定 request ID、step、最大 lag 白名单或可调常数。任一条失败、证据缺失、事件无法唯一匹配或根不在 schedule 1 初始 workload，归因门立即失败。

## 捕虫护栏

| 护栏 | 冻结要求 |
|---|---|
| real 侧约束 | sim-only 抢占不得触发例外。 |
| token 边界 | token 差大于累积根滞后必须失败。 |
| offset 边界 | 无验证事件处的对齐偏移跳变必须失败。 |
| root 边界 | 根不在 schedule 1 初始 workload 必须失败。 |
| oracle 不变量 | oracle 语义门绝对不允许例外。 |
